# CLAUDE.md — NewGame Platform

`gameclub-platform` (Zonup) asosida qurilayotgan yangi loyiha. Modullar eski loyihadan bosqichma-bosqich ko'chiriladi.

## Hozir bor
- `apps/api` (NestJS + Prisma + Redis): config, common (xatolar, response, rate-limit), audit, rbac, auth (OTP + parol + refresh rotation), telegram (OTP bot, polling/webhook), health.
- `apps/api` qo'shimcha: `club-applications` (landing ariza), `accounts` (super admin: klub+operator, menejer, parol tiklash, bloklash), `panels` (operator/menejer dashboard).
- `apps/web` (Next.js): landing (`/`), xarita (`/map`, geolokatsiya bo'yicha yaqin klublar), klub sahifasi (`/clubs/[id]`), klub arizasi (`/for-clubs`), mijoz login (`/login`, Telegram bot orqali kod). Ommaviy API: `catalog` moduli (`GET /clubs/map|latest|stats|:id`) — faqat ACTIVE va joyi belgilangan klublar. Xarita kaliti `apps/web/.env.local` → `NEXT_PUBLIC_YANDEX_MAPS_KEY`.
- Dizayn (`apps/web`): `template/design.html` maketi asosida. Tokenlar `app/globals.css` (`@theme`: qora `bg` #0A0A0A, lime `accent` #B6FF00, oq `paper`/`ink` kartalar, 2px chiziqlar), shriftlar `app/layout.tsx`: Anton (sarlavha — `font-display uppercase`, faqat 400) + Inter; Anton'da kirill yo'q — ruscha sarlavhalar Oswald'ga tushadi. Umumiy komponentlar `components/ui.tsx` (`Button`/`buttonClass`, `Option`, `Chip`, `StepLabel`, `BackButton`, `Hl`, `TwoTone`, `Modal`); `cx` klasslarni oddiy birlashtiradi — bir xil xususiyatni ustidan yozishda `!` qo'ying (`rounded-[24px]!`). Klub va bron sahifalari mobilda "ilova ekrani": header, pastki menyu va footer yashirin (`isImmersive`, `components/header.tsx`), o'rnida pastki BRON paneli. Sayt foni — `.gc-backdrop` (`app/layout.tsx` + `globals.css`): qotirilgan qatlam (setka, sekin siljiydigan lime nur, grain); `<body>` foni shaffof bo'lishi shart (rang `<html>` da), header tepada shaffof, surilganda qorayadi.
- Klubni ulashish: `apps/web/src/lib/share-card.tsx` (next/og ImageResponse, Zonup uslubi, QR) → `GET /clubs/:id/share?format=story|post|og&lang=` va `opengraph-image.tsx`. Shriftlar `src/assets/fonts` (statik TTF/WOFF: Anton, Oswald kirill, Manrope; Satori variable shrift va WOFF2 ni qo'llamaydi). QR va og:url `NEXT_PUBLIC_SITE_URL` dan. Admin panel (operator/menejer) shu rasmni `/share-card/:id` rewrite orqali oladi (`apps/admin/.env.local` → `WEB_ORIGIN`, `NEXT_PUBLIC_WEB_URL`).
- Google Analytics 4 (`apps/web`): `components/analytics.tsx` (next/script, `afterInteractive`), ID `apps/web/.env.local` → `NEXT_PUBLIC_GA_ID` (bo'sh — yuklanmaydi; build paytida yoziladi). Hodisalar brauzerdan to'g'ridan-to'g'ri Google'ga ketadi, API'ga yuk yo'q. SPA o'tishlarini GA'ning Enhanced measurement (history events) kuzatadi — `page_location` ni config'da qotirmang. Konversiya: `track("booking_created", {club_id, duration_minutes, seats})` (`lib/analytics.ts`) — parametrlarda shaxsiy ma'lumot bo'lmasin.
- `apps/admin` (Next.js, :4920): bitta login (username + parol), rolga qarab panel: `/platform` (SUPER_ADMIN), `/operator`, `/manager`.
- `packages/types` (`@ng/types`): API/session klienti, pul/vaqt helperlari.
- Operator zal sxemasi: `/operator/layout` — `zones.layout` JSON `{cols, rows, seats:[{n,x,y}], decor:[{kind,x,y}]}`, o'rindiqlar 1..`zones.devices_count`, `PUT /operator/zones/:id/layout` (`normalizeLayout`). Muharrir `apps/admin/src/components/zone-layout.tsx` (eski `room-editor.tsx` dan).
- Klub logotipi va rasmi (bittadan): operator `/operator/location` (klub sozlamalari, `components/club-images.tsx`) → `POST|DELETE /operator/club/logo|photo` (multipart `file`, ≤10 MB, JPG/PNG/WEBP; brauzer 3 MB dan kattasini oldin kichraytiradi). `media` moduli: sharp bilan qayta kodlanadi (webp, EXIF/GPS olib tashlanadi; logo 512 ichiga, rasm 1920), `STORAGE_DIR` (standart `apps/api/storage`) ga tasodifiy nom bilan saqlanadi, `clubs.logo_path/photo_path` — nisbiy yo'l. Ommaga `GET /api/v1/media/clubs/:id/<fayl>.webp` (immutable kesh, rate limitsiz); API javoblarida `logo_url/photo_url`. Saytda: klub sahifasi sarlavhasi (rasm fon), xarita ro'yxati va bosh sahifa kartalarida logotip (`ClubLogo`).
- Operator: zonalar (`zones`) va tariflar (`tariffs`, HOURLY/PACKAGE, narx tiyinda, ixtiyoriy vaqt oralig'i), ish vaqti (`clubs.working_hours` JSON) — `club-settings` moduli, soft delete.
- Obunalar (`subscriptions` moduli): super admin `/platform/plans` da rejalar (`plans`: narx tiyinda/oy, `max_zones`, `max_devices`) va `/platform/subscriptions` da klubga obuna (`club_subscriptions`: sinov kunlari + to'langan oylar, uzaytirish, amaldagisi `cancelled_at IS NULL`). Muddat tugasa klub yopilmaydi — faqat super adminga ogohlantirish (dashboard, menyu badge, 3 kun oldin). Limit operator zona qo'shish/qurilma sonini oshirishda tekshiriladi (`assertWithinLimits`); obuna bo'lmasa — cheklov yo'q.
- Bron (`bookings` moduli): `devices` (zona o'rindig'i, `seat_no` 1..`devices_count`, `syncDevices`), `bookings` + `booking_items` (EXCLUDE gist — bitta qurilma ikki marta band qilinmaydi, bufer 5 daq — `BOOKING_RULES.bufferMinutes`). Vaqtlar to'ri 30 daqiqalik (`slots`), lekin to'r vaqtida biror zona faqat tugayotgan bron + bufer tufayli to'la bo'lsa, shu zonada joy ochiladigan daqiqa ham qo'shiladi (11:00 da to'la → 11:05), aks holda bronlar orasida 30 daqiqa bo'sh qolardi. Mijoz: klub sahifasida (`/clubs/[id]`) bron ochiq turmaydi — «BRON QILISH» tugmasi `/clubs/[id]/book` ga olib boradi (faqat kirgan mijoz; kirmagan bo'lsa `/login?next=/clubs/:id/book&reason=book`, kirgach shu sahifaga qaytadi). Bron oqimi `components/booking-flow.tsx`: sana → necha soat → vaqt (30 daqiqalik kataklar `slots[].free`, yoki aniq daqiqa barabani) → zona → o'rindiq (zal sxemasi) → aloqa raqami → «Bron tasdiqlandi» ekrani (chipta `components/booking-ticket.tsx`); `/bookings` — mening bronlarim. Aloqa raqami (`bookings.contact_phone`, `POST /bookings` → `contact_phone`, +998XXXXXXXXX; berilmasa akkaunt raqami): akkaunt raqami Telegram orqali tasdiqlanadi va qo'ng'iroq qabul qilmasligi mumkin, shuning uchun maydon oxirgi bronda ishlatilgan raqam bilan (`GET /me/booking-contact`; birinchi safar — akkaunt raqami) to'ldiriladi, mijoz o'zgartira oladi va «TASDIQLASH»dan oldin «Raqam to'g'rimi?» oynasi chiqadi. Operator panelida qo'ng'iroq raqami — `contact_phone ?? customer.phone` (farq qilsa akkaunt raqami ham ko'rsatiladi). Qoidalar `BOOKING_RULES`: to'lov klubda (darhol CONFIRMED), 5 kun oldin, ≤5 faol bron, bitta bronda ≤5 o'rindiq (`maxDevices`), bekor qilish ≥1 soat oldin, faqat CUSTOMER. Narx `pricing.ts` (HOURLY har 30 daq eng arzon mos tarif yoki PACKAGE). Operator `/operator/bookings`: keldi/kelmadi/bekor (kelmadi — boshlanishdan `noShowAfterMinutes`=10 daq keyin). Operator bosh sahifasi (`components/new-bookings.tsx`): kod bo'yicha qidirish (`GET /operator/bookings/by-code/:code`), statistika kartalari va kutilayotgan bronlar (`GET /operator/bookings/upcoming`, 10 s), bron oynasida zal sxemasi + qo'ng'iroq natijasi (`bookings.contact_status` NEW|CONFIRMED|PREPAID|NO_ANSWER, `PUT /operator/bookings/:id/contact`).
- Joyida bron (walk-in): operator `/operator/walk-in` — vaqt ("hozir" yoki soat) → davomiylik → o'rindiqlar (zal sxemasi), ism/telefon ixtiyoriy. `GET /operator/bookings/availability`, `POST /operator/bookings/walk-in`: `bookings.source=WALK_IN`, `customer_id` ixtiyoriy (telefon mavjud mijozniki bo'lsa bog'lanadi), `guest_name/guest_phone`, hozir boshlansa darhol CHECKED_IN; ≤20 o'rindiq, mijoz limitlari qo'llanmaydi.
- Ochiq vaqt (`bookings.is_open`): tugashi oldindan noma'lum sessiya — faqat operator ochadi va faqat operator to'xtatadi (mijoz saytdan bunday bron qila olmaydi), istalgan zonada (soatlik tarifi bo'lsa). Ochish: `/operator/walk-in` da «Ochiq vaqt» → `POST /operator/bookings/walk-in {open:true}` (hozirdan, darhol CHECKED_IN); mavjudlik `GET /operator/bookings/availability?open=1` (narx soatiga, har bir joy uchun `free_until`/`limited_by`). `end_at` — vaqtinchalik chegara: klub yopilishi / `maxOpenMinutes`=12 soat / shu joydagi keyingi bron − bufer (joy shungacha band, saytda bo'sh ko'rinmaydi). To'xtatish: `POST /operator/bookings/:id/stop` (`closeOpen`): haqiqiy tugash, davomiylik va summa yoziladi — faqat HOURLY tariflar bo'yicha daqiqasiga (`pricing.ts` → `openQuote`), 100 so'mgacha yaxlitlanadi (`openRoundTiyin`). To'xtatilmay chegaraga yetsa — ro'yxat o'qilganda o'zi yopiladi (`finalizeExpiredOpen`). Xato ochilgan sessiya — operator «bekor qilish». Panelda: bosh sahifa «Ochiq vaqt» bloki (o'tgan vaqt, hozirgi summa, «To'xtatish» → yakuniy summa oynasi, `components/open-session.tsx`) va `/operator/bookings`.
- Telegram Mini App: `apps/web` ning o'zi Telegram ichida ochiladi (`/tg` kirish sahifasi, `lib/telegram.tsx` — SDK, avtomatik kirish, BackButton, `html[data-tg]` da footer yashirin). Backend `POST /auth/telegram-webapp` (`auth/telegram-webapp.service.ts`: initData HMAC tekshiruvi, `telegram_links.tg_user_id` → `loginWithPhone`; raqam yo'q bo'lsa `need_contact` → Mini App `requestContact()`, kontakt botga keladi va `OtpService.onContact` bog'laydi). Bot menyu tugmasi va raqam bog'langach "Bron qilish" web_app tugmasi — `TELEGRAM_WEBAPP_URL` (faqat https) bo'lsa.
- Hali yo'q (eski loyihada bor): sessiya, onlayn to'lov, Telegram bot menyusi (`telegram-bot.service.ts` — bronlarga bog'liq), mobile.

## Akkaunt modeli
- Klub egasi landing'da ariza qoldiradi → super admin `/platform/applications` da ko'radi → "Klub + operator yaratish".
- Har bir filial = alohida `clubs` qatori + o'z OPERATOR akkaunti (`user_roles.club_id`). 2 filial — 2 klub, 2 operator.
- Super admin MANAGER akkauntlarini ham yaratadi. Parol berilmasa vaqtinchalik parol (faqat javobda), birinchi kirishda almashtiriladi.
- Har bir xodimda 7 xonali `users.public_id` (User ID). Operator uni menejerga aytadi → menejer `/manager` da kiritadi → `manager_link_requests` da 6 xonali kod yaratiladi va operator panelida ko'rinadi (10 daqiqa, 5 urinish) → operator kodni menejerga aytadi → menejer kodni kiritsa `manager_clubs` ga bog'lanadi. Operator ulanish so'rovini rad etishi mumkin. Menejerni olib tashlash — operator `manager_unlink_requests` so'rovi → super admin `/platform/removals` da ikkala tomon bilan bog'lanib tasdiqlaydi.
- Operator birinchi kirishda klub joyini Yandex xaritada belgilaydi (`clubs.latitude/longitude`), belgilanmaguncha operator paneli ochilmaydi (`app/(panel)/operator/layout.tsx`). Xarita: `apps/admin/.env.local` → `NEXT_PUBLIC_YANDEX_MAPS_KEY` (JS API 2.1). Qidiruv/teskari geokodlash — API proksisi `GET /geo/search|reverse` (`apps/api/.env` → `YANDEX_GEOCODER_KEY`, HTTP Geocoder, faqat serverda, Redis kesh 24 soat). Kalitlar git'ga tushmaydi.
